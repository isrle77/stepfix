Questions

What is it, in one sentence?

A small widget you paste into your website that asks visitors a few questions and leads them to the right answer or fix, like a support agent's checklist turned into buttons.

Is the free version really free?

Yes. The free builder makes troubleshooters with up to 10 steps (questions and solutions together). It gives you embed code that you paste into your site, with a small "Powered by ISRS Tech Portal" link in the widget. No account, no email, no time limit.

What do I get with the full version?

Unlimited steps, no "Powered by" link, JSON import and export, the visual editor as a file you keep and use offline, the widget source, 4 ready-made templates, a setup guide for WordPress, Shopify, Wix and Squarespace, and an event API for analytics. It is a one-time purchase on Gumroad.

Do I need a server, database or subscription?

No. Everything is static HTML and JavaScript that runs in the visitor's browser. Paste the code into your site and you're done. There's nothing to host and nothing that can go down on our side.

Which website builders does it work with?

Any site where you can add custom HTML with JavaScript: WordPress, Shopify, Webflow, Wix, Squarespace, Ghost, Carrd and plain HTML. Some builders only allow custom code on paid plans; check your plan if the widget doesn't appear.

Does it work in other languages, including Hebrew and Arabic?

Yes. Write your questions in any language. Right-to-left layout turns on automatically for RTL languages, and the button texts can be translated.

Is my data sent anywhere?

No. The builder saves your work only in your own browser. The widget doesn't use cookies, doesn't track visitors and makes no calls to us. See the privacy page.

Will it slow my site down or clash with my theme?

The widget is about 20 KB with no dependencies. It renders inside a Shadow DOM, so your theme's CSS can't break it and it can't change your site.

Can I get a refund?

Refunds are handled through Gumroad according to the policy shown on the product page.
